# Jebwach Travel Safari

A responsive tours and travel website built with HTML, CSS and JavaScript.

## Website Pages

- Home: index.html
- About Us: about.html
- Destinations: destinations.html
- Tour Packages: tours.html
- Contact: contact.html

## Technologies

- HTML5 for website structure
- CSS3 for styling and responsive layouts
- JavaScript for interactive navigation and form feedback
- Git and GitHub for version control and deployment

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open index.html.
3. Run the website using the Live Server extension.
4. Navigate between the pages to test the links.

An internet connection is required for the externally hosted photographs.

## Important Before Launch

- Replace placeholder contact details with official business contacts.
- Confirm tour prices, services and travel arrangements.
- Configure a secure method of receiving customer enquiries.
- Review all images and their usage permissions.
- Test the website on mobile devices and desktop browsers.
- Publish through GitHub Pages or another suitable hosting service.
